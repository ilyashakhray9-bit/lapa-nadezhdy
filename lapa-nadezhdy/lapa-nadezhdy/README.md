# Лапа надежды

Готовый локальный прототип для портфолио. Демонстрационный проект: животные и заявки вымышленные.

## Запуск

1. Если скачали ZIP, распакуйте его целиком.
2. Откройте `index.html` двойным щелчком в современном Edge, Chrome, Firefox или Safari.
3. Сайт работает без установки, сборки, сервера и интернета. JavaScript должен быть включён.

Не переносите `index.html` отдельно: рядом должны оставаться `styles.css`, `app.js` и папка `assets`.

## Что можно попробовать

- Адаптивную главную страницу и навигацию по разделам.
- Шесть анкет: Солнечный, Бим, Буся, Луна, Тедди и Молли.
- Совместные фильтры по возрасту, размеру и характеру; состояние без результатов и сброс.
- Подробную анкету через «Познакомиться»; закрытие крестиком, клавишей Escape или нажатием за пределами окна.
- Учебную заявку: откройте анкету → «Попробовать заявку» → «Заполнить примером» → отметьте понимание деморежима → «Проверить демозаявку».
- Обязательные поля и проверку email. Форма ничего не отправляет. После завершения или закрытия введённые значения очищаются.
- Раскрывающиеся ответы на вопросы.

Возрастные группы: до 1 года, от 1 года до 7 лет включительно, от 8 лет. Размер щенка — текущий. Фильтры действуют одновременно; два признака характера в анкете позволяют найти её по любому из них.

## Файлы и редактирование

- `index.html` — разделы страницы и окна анкеты/заявки.
- `styles.css` — палитра, адаптивная вёрстка и состояния фокуса.
- `app.js` — шесть статических анкет, фильтрация, управление окнами и учебной формой. Измените массив `dogs`, чтобы отредактировать героев.
- `assets/` — локальные фотографии и значок лапы; `SOURCES.txt` содержит источники и ссылку на лицензию.

HTML, CSS, vanilla JavaScript. Без библиотек, API, аналитики, cookies, localStorage, внешних шрифтов, платёжных реквизитов и сетевой отправки. Обычные ссылки на источники открывают интернет только при нажатии. Шрифты системные: Segoe UI/Arial и Georgia; вид может немного отличаться между устройствами.
